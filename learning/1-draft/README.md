# 1-Draft: Collect Stories

**Goal:** Gather raw material — stories to cover all questions.

## How to Practice

1. Run `1-draft-random` or `1-draft-selected` command
2. Answer the question by voice
3. AI saves session and vocabulary

## When to Recap

Every 1-2 weeks run `1-draft-recap` to check question coverage.

## When to Move to 2-Refine

- [ ] 5-7 unique stories
- [ ] Core topics covered: technical, conflict, leadership, failure, mentorship
- [ ] 15+ questions answerable (directly or by stretching a story)
