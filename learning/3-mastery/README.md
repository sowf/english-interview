# 3-Mastery: Daily Practice

**Goal:** Maintain skills and reach fluency.

## Recommended Daily Routine (~30 min)

### 1. Grammar Exercise (5 min)
Run `english-grammar-at` — get a random grammar exercise, solve it.

### 2. Anki Review (10 min)
Open Anki → Review due cards + learn 10 new.

### 3. Tell One Story (15 min)
Run `3-mastery-practice` — answer a question without reading your notes.

## Weekly

- [ ] All stories practiced at least once
- [ ] Anki streak maintained
- [ ] Grammar exercises daily

## Success Criteria

- Can tell any story naturally without notes
- Filler words < 8 per story
- Scores consistently 80+/100
- Vocabulary feels automatic, not memorized

## Commands

| Command | What it does |
|---------|--------------|
| `english-grammar-at` | Random grammar exercise |
| `3-mastery-anki` | Generate Anki deck |
| `3-mastery-practice` | Full practice session with scoring |
