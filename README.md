# 🎤 English Interview Prep

Behavioral interview preparation framework for Senior Software Engineers.

---

## ⚡ Start Now

1. Open Cursor command palette: `Cmd+Shift+P`
2. Type: `1-draft-random`
3. AI asks you a behavioral question
4. Click 🎤 microphone and answer by voice (Mac: `F5` for dictation if mic doesn't work)
5. Get feedback + improved C1 version + vocabulary

**That's it.** Do this daily for 2-4 weeks → you'll have 5-7 polished stories.

---

## 🎯 Three Phases

| | Phase | What you do | Time |
|---|-------|-------------|------|
| 📝 | **1-Draft** | Answer questions, collect stories | 2-4 weeks |
| 🔧 | **2-Refine** | Structure into STARR, practice execution | 1-2 weeks |
| 🚀 | **3-Mastery** | Anki + grammar + freestyle | ongoing |

## 🏁 Ready for Interview When

- ✅ 7+ stories covering all core topics
- ✅ Can tell any story without notes
- ✅ Scores 80+/100 consistently
- ✅ Filler words < 8 per answer
